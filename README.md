## 🎨 风格特点

- 清雅教学风：墨青 / 暖金 / 米白 + 直角细线，去掉糖果配色
- 中文字体（楷体）显示生字、课文，更接近课本
- 拼音字卡、田字格写字示范、词语卡
- 课文段落、生字、词语均有 **🔊 朗读** 按钮（浏览器语音合成 zh-CN）
- 课件支持 **✏️ 手写批注**：右下角"手写"开关，可换颜色 / 笔粗 / 橡皮 / 清空
- 两个互动小练习：拼音选择 + 选词填空

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可全屏播放（建议按 F11 进入全屏）。

### 操作快捷键

- `→` / `空格` / `PageDown`：下一页
- `←` / `PageUp`：上一页
- `Home` / `End`：跳到首页 / 末页

### 答案互动

- 点击右下角 **"显示答案"** 按钮一键显示/隐藏所有答案
- 也可单独点击页面中带虚线的空白处显示该题答案
- 闯关游戏点击选项即可作答，正确选项会变绿

### 朗读 / 手写

- 生字卡、词语、课文段落上的 **朗读** 按钮：朗读对应文字（需浏览器支持中文 TTS，推荐 Chrome / Edge）
- 控制条上的 **🖊️ 手写** 按钮：进入板书模式，可在课件上画线、改颜色、用橡皮、清空当前页
- 翻页会自动停止朗读；每页的批注会保留

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可全屏播放（建议按 F11 进入全屏）。

### 操作快捷键

- `→` / `空格` / `PageDown`：下一页
- `←` / `PageUp`：上一页
- `Home` / `End`：跳到首页 / 末页
- `P`：开启/关闭画笔

### 互动功能

- 点击右下角 **"显示答案"** 按钮一键显示/隐藏所有答案
- 也可单独点击页面中带虚线的空白处显示该题答案
- 第 16 页选择题可点击选项与蓬蓬狗互动，答对会撒花庆祝 🎉🐾
- 画笔工具支持画笔/荧光笔/橡皮三种模式，可按页保存批注

## 🎨 风格特点

- 整体可爱风：粉色/嫩黄/嫩绿 + 圆胖圆角 + 蹦跳动画
- 拼音字卡、田字格写字示范、词语花朵
- 鼹鼠先生作为讲解员陪小朋友学习
- 两个互动小游戏：拼音选择 + 选词填空

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可全屏播放（建议按 F11 进入全屏）。

### 操作快捷键

- `→` / `空格` / `PageDown`：下一页
- `←` / `PageUp`：上一页
- `Home` / `End`：跳到首页 / 末页

### 答案互动

- 点击右下角 **"显示答案"** 按钮一键显示/隐藏所有答案
- 也可单独点击页面中带虚线的空白处显示该题答案
- 闯关游戏点击选项即可作答，答对会有 🌸 反馈
